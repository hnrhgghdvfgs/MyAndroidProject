# Раздел 5. GitHub Projects и этапы разработки

## 5.1. Структура репозитория

```
/
├── .gitignore              # исключения Android/Gradle/IDE
├── README.md               # описание проекта и скриншоты
├── build.gradle            # корневой build-файл
├── settings.gradle
├── gradle.properties
├── gradlew / gradlew.bat    # Gradle wrapper (создаётся автоматически)
├── doc/
│   ├── 01-analysis.md      # анализ предметной области и схема БД
│   ├── 02-user-guide.md    # руководство пользователя
│   ├── 03-admin-guide.md   # руководство администратора
│   ├── 04-test-plan.md     # тест-кейсы
│   └── 05-github-projects.md
└── app/
    └── src/main/…          # исходный код, ресурсы, манифест
```

## 5.3. Рекомендуемая история коммитов

Чтобы история отражала реальный прогресс по этапам:

```bash
git init
git add .
git commit -m "Этап 1: инициализация проекта и структура репозитория"
git add doc/01-analysis.md
git commit -m "Этап 1: анализ предметной области и схема базы данных"
git add app/src/main/res
git commit -m "Этап 2: верстка экранов, стили и темы"
git add app/src/main/java/com/example/socialnetwork/data
git commit -m "Этап 3: SQLiteOpenHelper, схема и репозитории"
git add app/src/main/java/com/example/socialnetwork/ui app/src/main/java/com/example/socialnetwork/util
git commit -m "Этап 4: бизнес-логика, адаптеры и фоновая работа с БД"
git add doc/04-test-plan.md README.md
git commit -m "Этап 5: тест-кейсы и документация"
git commit --allow-empty -m "Этап 6: релизная сборка APK"
```

## 5.4. Публикация релиза

1. Собрать APK: `gradlew.bat assembleDebug`.
2. На GitHub открыть `Releases → Draft a new release`.
3. Указать тег `v1.0`, название «Круг — социальная сеть».
4. Прикрепить `app-debug.apk` и краткое описание изменений.
5. Опубликовать релиз.

## 5.5. Скриншоты для README

Рекомендуемый набор: экран входа, лента, экран публикации с комментариями и фото, профиль,
чаты, переписка, админ-панель и тёмная тема. Сложить в `doc/screens/` и вставить в README.
