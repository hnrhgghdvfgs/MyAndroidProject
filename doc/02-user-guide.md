# Раздел 2. Руководство пользователя

## 2.1. Первый запуск

При первом запуске открывается экран **входа**. Если учётной записи нет, нажмите
«Создать» и заполните форму регистрации:

- **Имя и фамилия** — отображаемое имя (обязательно);
- **Логин** — минимум 3 символа, должен быть уникальным;
- **Пароль** — минимум 6 символов;
- **Повтор пароля** — должен совпадать с паролем.

После успешной регистрации выполняется автоматический вход на главный экран.

Для быстрого знакомства с приложением можно нажать на подсказку внизу экрана входа —
поля заполнятся демо-учётной записью `anna / 123456`.

## 2.2. Навигация

Внизу главного экрана расположена панель из пяти разделов:

| Раздел | Назначение |
|--------|-----------|
| **Лента** | Публикации сообщества с вкладками «Все», «Подписки», «Популярное». |
| **Поиск** | Поиск публикаций в реальном времени. |
| **Создать** | Открывает форму новой публикации (текст и необязательное фото). |
| **Чаты** | Личные переписки и непрочитанные сообщения. |
| **Профиль** | Данные профиля, статистика, настройки и свои публикации. |

## 2.3. Лента

- **Все** — все публикации, кроме записей заблокированных пользователей.
- **Подписки** — записи авторов, на которых вы подписаны, и ваши собственные.
- **Популярное** — сортировка по количеству лайков.

Карточка публикации показывает автора, время, категорию, заголовок и начало текста.
Нажмите на карточку, чтобы открыть полную публикацию.

**Лайк** — нажмите на сердечко в карточке или на экране публикации. Повторное нажатие убирает лайк.

## 2.4. Публикация и комментарии

На экране публикации доступны:

- полный текст и категория;
- кнопка **«Подписаться» / «Вы подписаны»** рядом с публикацией другого автора;
- комментарии и поле ввода внизу экрана.

Введите комментарий и нажмите кнопку отправки. Комментарий появится в списке, счётчик обновится.

**Удаление**: долгое нажатие на карточку публикации (в ленте, поиске или профиле) или на
комментарий открывает диалог подтверждения. Удалять можно свои записи; администратор может
удалять любые.

## 2.5. Создание публикации

1. Нажмите **«Создать»** на нижней панели.
2. Введите заголовок (до 80 символов) и текст.
3. При необходимости нажмите **«Добавить фото»** и выберите изображение в галерее — появится
   предпросмотр; фото можно заменить или удалить крестиком.
4. Выберите категорию из списка.
5. Нажмите **«Опубликовать»**.

Пустые поля подсвечиваются ошибкой, запись не создаётся. Фото необязательно. После успешного
сохранения приложение возвращается в ленту, где сразу видна новая публикация (с фотографией,
если она была добавлена).

## 2.6. Сообщения

Раздел **«Чаты»** содержит список диалогов:

- у каждого диалога видны имя собеседника, последнее сообщение, время и счётчик непрочитанных;
- на иконке вкладки отображается общее число непрочитанных сообщений;
- нажатие открывает переписку, долгое нажатие — удаление переписки с подтверждением.

В переписке:

- ваши сообщения показаны справа фиолетовыми пузырями, сообщения собеседника — слева;
- введите текст и нажмите кнопку отправки (или оставьте поле пустым — появится ошибка);
- при открытии чата входящие сообщения автоматически помечаются прочитанными;
- новый диалог: кнопка **«+»** в разделе «Чаты» (или **«Сообщения»** в профиле) открывает
  список пользователей с поиском по имени и логину;
- начать переписку можно также с экрана публикации — кнопка **«Написать сообщение»**.

## 2.7. Поиск

Начните вводить запрос — результаты обновляются по мере ввода. Ищутся совпадения по
заголовку, тексту, категории и имени автора. Над списком отображается количество найденных
публикаций или сообщение «Ничего не найдено».

## 2.8. Профиль

В профиле отображаются аватар с инициалами, имя, логин, описание и статистика:
количество публикаций, подписчиков и полученных лайков. Ниже — список своих публикаций
и настройки:

- **Тёмная тема** — переключатель светлого/тёмного оформления (выбор сохраняется);
- **Редактировать профиль** — изменение имени и описания;
- **Сообщения** — список пользователей, чтобы начать новый диалог;
- **Админ-панель** — отображается только для администратора;
- **Выйти из аккаунта** — завершает сессию после подтверждения.

## 2.9. Ориентация экрана

Приложение поддерживает портретную и альбомную ориентацию. При повороте устройства
введённый текст, выбранные вкладки и позиция списков сохраняются; экран входа в альбомном
режиме перестраивается в две колонки.

## 2.10. Возможные сообщения

| Сообщение | Причина |
|-----------|---------|
| «Неверный логин или пароль» | Неверные учётные данные. |
| «Аккаунт заблокирован администратором» | Пользователь заблокирован в админ-панели. |
| «Этот логин уже занят» | Логин уже существует (регистронезависимо). |
| «Пароль должен содержать минимум 6 символов» | Слишком короткий пароль. |
| «Пароли не совпадают» | Поле подтверждения не совпало. |
| «Введите сообщение» | Попытка отправить пустое сообщение в чате. |
