# Раздел 4. План тестирования (тест-кейсы)

Окружение: эмулятор или устройство Android 7.0+, чистая установка приложения.

| ID | Название | Предусловие | Шаги | Ожидаемый результат |
|----|----------|-------------|------|---------------------|
| TC-01 | Регистрация нового пользователя | Приложение запущено, открыт экран регистрации | 1. Ввести имя. 2. Ввести уникальный логин. 3. Ввести пароль и повтор. 4. Нажать «Зарегистрироваться» | Toast «Регистрация успешна», переход на главный экран, запись добавлена в `users` |
| TC-02 | Валидация пустых полей | Открыт экран авторизации | 1. Оставить логин и пароль пустыми. 2. Нажать «Войти» | `setError` на полях, вход не выполняется |
| TC-03 | Добавление публикации | Пользователь авторизован, открыта форма создания | 1. Заполнить заголовок и текст. 2. Выбрать категорию. 3. Нажать «Опубликовать» | Экран закрывается, Toast «Публикация добавлена», новая карточка появляется в начале ленты |
| TC-04 | Сохранение состояния при повороте | Открыта форма создания, введён текст | 1. Повернуть устройство в альбомную ориентацию. 2. Вернуть в портретную | Разметка перестраивается, введённый текст и выбранная категория не теряются |
| TC-05 | Удаление публикации | Открыта лента, есть своя публикация | 1. Долго нажать на карточку. 2. Подтвердить удаление | Карточка исчезает из `RecyclerView`, Toast «Публикация удалена», строка удалена из БД вместе с комментариями |
| TC-06 | Вход с неверным паролем | Открыт экран входа | 1. Ввести `anna`. 2. Ввести `wrong`. 3. Нажать «Войти» | Ошибка «Неверный логин или пароль», главный экран не открывается |
| TC-07 | Уникальность логина | Открыт экран регистрации | 1. Ввести существующий логин `anna`. 2. Заполнить остальные поля. 3. Нажать «Зарегистрироваться» | Ошибка «Этот логин уже занят», пользователь не создаётся |
| TC-08 | Лайк и повторный лайк | Открыта лента | 1. Нажать на сердечко в карточке. 2. Нажать повторно | Счётчик увеличивается на 1 и окрашивается, затем уменьшается; в таблице `likes` появляется/удаляется строка |
| TC-09 | Комментирование | Открыт экран публикации | 1. Ввести комментарий. 2. Нажать отправку | Комментарий появляется в списке, счётчик и заголовок «Комментарии (N)» обновляются, поле очищается |
| TC-10 | Валидация комментария | Открыт экран публикации | 1. Оставить поле пустым. 2. Нажать отправку | `EditText.setError`, комментарий не создаётся |
| TC-11 | Подписка на автора | Открыта публикация другого автора | 1. Нажать «Подписаться». 2. Открыть вкладку «Подписки» | Кнопка меняется на «Вы подписаны», публикации автора появляются во вкладке |
| TC-12 | Поиск в реальном времени | Открыт раздел «Поиск» | 1. Ввести `кофе` | Список обновляется по мере ввода, отображается количество результатов; при бессмысленном запросе — «Ничего не найдено» |
| TC-13 | Редактирование профиля | Открыт профиль | 1. Нажать «Редактировать профиль». 2. Изменить имя и описание. 3. Сохранить | Toast «Профиль сохранён», имя и описание обновились в профиле и на карточках публикаций |
| TC-14 | Смена темы | Открыт профиль | 1. Включить «Тёмная тема». 2. Перезапустить приложение | Все экраны в тёмном оформлении, выбор сохраняется |
| TC-15 | Блокировка пользователя | Вход под `admin`, открыта админ-панель | 1. Нажать «Заблокировать» у пользователя `lena` | Статус меняется на «Заблокирован», публикации исчезают из ленты, вход под `lena` невозможен |
| TC-16 | Разблокировка пользователя | Пользователь заблокирован | 1. Нажать «Разблокировать» | Статус «Активен», вход и публикации снова доступны |
| TC-17 | Удаление пользователя | Открыта админ-панель | 1. Нажать «Удалить» у пользователя. 2. Подтвердить | Пользователь исчезает из списка и статистики, его публикации/комментарии/лайки удалены каскадно |
| TC-18 | Защита аккаунта администратора | Открыта админ-панель | 1. Найти собственную учётную запись | Кнопки блокировки и удаления скрыты |
| TC-19 | Пустая лента | Новый пользователь без подписок | 1. Открыть вкладку «Подписки» | Отображается заглушка «Вы ещё ни на кого не подписаны», приложение не падает |
| TC-20 | Быстрое переключение вкладок | Открыт главный экран | 1. Несколько раз переключить вкладки нижней навигации | Приложение работает без падений, состояние экранов сохраняется |
| TC-21 | Добавление фото к публикации | Пользователь авторизован, открыта форма создания | 1. Нажать «Добавить фото». 2. Выбрать изображение в галерее. 3. Заполнить поля и опубликовать | Появляется предпросмотр, после публикации фото отображается в ленте и на экране публикации; файл сохранён в `files/post_images` |
| TC-22 | Замена и удаление фото | В форме создания выбрано фото | 1. Нажать «Заменить фото» и выбрать другое. 2. Нажать крестик на предпросмотре | Предпросмотр обновляется, затем скрывается; публикация создаётся без изображения |
| TC-23 | Удаление публикации с фото | Есть своя публикация с фото | 1. Долго нажать на карточку. 2. Подтвердить удаление | Публикация исчезает, файл изображения удаляется из хранилища |
| TC-24 | Открытие списка чатов | Пользователь `anna` авторизован | 1. Нажать вкладку «Чаты» | Отображаются диалоги с `max` и `lena`, у непрочитанных — счётчик; на иконке вкладки значок непрочитанных |
| TC-25 | Отправка сообщения | Открыт чат с пользователем `max` | 1. Ввести текст. 2. Нажать кнопку отправки | Сообщение появляется справа, поле очищается, диалог поднимается в начало списка |
| TC-26 | Валидация пустого сообщения | Открыт чат | 1. Оставить поле пустым. 2. Нажать отправку | `EditText.setError` «Введите сообщение», сообщение не создаётся |
| TC-27 | Прочтение сообщений | У `anna` есть непрочитанные от `max` | 1. Открыть чат с `max`. 2. Вернуться к списку чатов | Счётчик диалога и значок на вкладке сбрасываются, в БД `is_read = 1` |
| TC-28 | Новый диалог через поиск | Открыт раздел «Чаты» | 1. Нажать «+». 2. Ввести имя или логин пользователя. 3. Выбрать пользователя | Открывается пустой чат с выбранным собеседником, можно отправить первое сообщение |
| TC-29 | Начало переписки с публикации | Открыта публикация другого автора | 1. Нажать «Написать сообщение» | Открывается чат с автором публикации |
| TC-30 | Удаление переписки | В списке чатов есть диалог | 1. Долго нажать на диалог. 2. Подтвердить удаление | Диалог исчезает из списка, сообщения удалены из таблицы `messages` |
| TC-31 | Защита от сообщения самому себе | Открыт список пользователей для нового чата | 1. Проверить список | Текущий пользователь в списке отсутствует |
| TC-32 | Сохранение фото при повороте | В форме создания выбрано фото | 1. Повернуть устройство | Предпросмотр фото сохраняется |

## Известные ограничения

- Данные локальные: несколько устройств не синхронизируются между собой.
- Личные сообщения работают внутри одного устройства; обновление переписки выполняется
  периодическим опросом базы (раз в 3 секунды), без push-уведомлений и сервера.
- В публикациях поддерживается одно фото; видео и несколько вложений не реализованы.
- Восстановление пароля не реализовано (учебный офлайн-проект).
