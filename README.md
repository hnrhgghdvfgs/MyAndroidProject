# Круг — Android-приложение социальной сети

Учебный индивидуальный проект по теме **«Социальная сеть»** (Блок 1: контент, медиа и общение).

Приложение полностью автономно: данные хранятся в локальной базе SQLite, интернет не требуется.
Реализованы регистрация и вход, лента публикаций с вкладками, лайки, комментарии, подписки,
поиск, личные сообщения (чаты), фотографии в публикациях, редактирование профиля,
светлая/тёмная тема и панель администратора.

## Демо-аккаунты

| Роль | Логин | Пароль |
|------|-------|--------|
| Пользователь | `anna` | `123456` |
| Пользователь | `max` | `123456` |
| Пользователь | `lena` | `123456` |
| Администратор | `admin` | `admin123` |

При первом запуске база автоматически заполняется демонстрационными публикациями,
комментариями, лайками, подписками и переписками (у `anna` есть непрочитанные сообщения).

## Возможности

- **Авторизация и регистрация** с валидацией полей (`setError`, проверка длины пароля, совпадения паролей, уникальности логина).
- **Лента** (`ViewPager2` + `TabLayout`): «Все», «Подписки», «Популярное».
- **Публикации**: создание с валидацией, удаление (автор или администратор), счётчики лайков и комментариев.
- **Фотографии в публикациях**: выбор изображения из галереи, предпросмотр, замена и удаление; фото копируется во внутреннее хранилище приложения и показывается в ленте, поиске и на экране публикации.
- **Личные сообщения (чаты)**: список диалогов с последним сообщением и счётчиком непрочитанных, переписка в виде пузырей, отправка сообщений, отметка о прочтении, значок непрочитанных на нижней навигации, выбор собеседника с поиском, удаление переписки.
- **Экран деталей**: полный текст, фото, лайк, подписка на автора, кнопка «Написать сообщение», комментарии и удаление своих комментариев.
- **Поиск в реальном времени** по заголовку, тексту, категории и имени автора.
- **Профиль**: аватар с инициалами, статистика, редактирование, свои публикации, выход.
- **Панель администратора**: статистика, блокировка/разблокировка и удаление пользователей.
- **Светлая и тёмная тема**, все строки вынесены в `strings.xml`, размеры — в `dimens.xml`, цвета — в `colors.xml`.
- Поддержка портретной и альбомной ориентации с сохранением состояния (отдельная разметка для `activity_login` в `layout-land`).

## Технологии

- Java 17, Android SDK (minSdk 24, targetSdk 34, compileSdk 35)
- XML-разметка: `ConstraintLayout`, `LinearLayout`, `MaterialCardView`
- `RecyclerView` + `ListAdapter` + `DiffUtil` + кастомные `ViewHolder`
- `SQLiteOpenHelper`, 6 связанных таблиц с `FOREIGN KEY`, паттерн Repository
- Все операции с БД — в фоновых потоках (`ExecutorService` + `Handler`), UI обновляется в главном потоке
- `SharedPreferences` для сессии и выбора темы
- Material Components 3 (BottomNavigationView, TextInputLayout, MaterialSwitch, MaterialAlertDialog, BadgeDrawable)
- Выбор фото через `ActivityResultContracts.GetContent`; изображения сжимаются и хранятся в приватной папке приложения

## Схема базы данных

Подробное описание — в [`doc/01-analysis.md`](doc/01-analysis.md).

```
users (1) ──< posts (1) ──< comments
  │             │
  │             └──< likes
  ├──< subscriptions (follower_id → users.id, following_id → users.id)
  └──< messages (sender_id → users.id, recipient_id → users.id)
```

- `users` — аккаунты, роль (`user` / `admin`), блокировка;
- `posts` — публикации, необязательный путь к фото `image_path`, `FOREIGN KEY(user_id) ON DELETE CASCADE`;
- `comments` — комментарии, каскадное удаление по посту и пользователю;
- `likes` — уникальная пара `(post_id, user_id)`;
- `subscriptions` — уникальная пара `(follower_id, following_id)`;
- `messages` — личные сообщения: отправитель, получатель, текст, признак прочтения, каскадное удаление по пользователю.

## Сборка

### Android Studio
1. `File → Open` → выбрать корневую папку проекта.
2. Дождаться синхронизации Gradle.
3. Запустить конфигурацию `app` на эмуляторе или устройстве (Android 7.0+).

### Командная строка
```bash
# Windows
gradlew.bat assembleDebug

# macOS / Linux
./gradlew assembleDebug
```
Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

> Если Gradle-обёртка отсутствует, выполните `gradle wrapper --gradle-version 8.9` или откройте проект в Android Studio — она создаст обёртку автоматически.
